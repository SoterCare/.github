# Contributing to SoterCare

Thank you for your interest in contributing!

We welcome developers, designers, researchers, students, and healthcare enthusiasts from all backgrounds.

## Ways to Contribute

- Fix bugs
- Improve documentation
- Add new features
- Review Pull Requests
- Report issues
- Improve UI/UX
- Write tutorials
- Suggest ideas

## Workflow

1. Fork the repository
2. Create a new branch
3. Commit your changes
4. Push your branch
5. Open a Pull Request

## Code Style

- Write clean code
- Document your work
- Keep Pull Requests focused
- Test before submitting

## Be Respectful

We value collaboration, inclusion, and constructive feedback.

Thank you for helping improve SoterCare ❤️
