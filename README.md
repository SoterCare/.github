# .github

This is [SoterCare](https://github.com/SoterCare)'s special community-health repository.

- **[profile/README.md](profile/README.md)** — renders as the organization's public profile at [github.com/SoterCare](https://github.com/SoterCare)
- **[CONTRIBUTING.md](CONTRIBUTING.md)** and **[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)** — default community health files, automatically used by any SoterCare repository that doesn't have its own copy
- **[.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/)** and **[.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md)** — default issue and pull request templates, used org-wide as a fallback

For the full community hub — events, guides, resources — see **[SoterCare/community](https://github.com/SoterCare/community)**.
