# 🌍 About Us

SoterCare is a student-led developer community focused on building technology that improves healthcare through Artificial Intelligence, Cloud Computing, Internet of Things (IoT), Software Engineering, and Mobile Development.

Beyond building products, our mission is to create opportunities for students to gain real-world experience by collaborating on projects, participating in open-source initiatives, organizing technical events, and mentoring the next generation of developers.

We believe the best way to learn is by building together.
